# E-Commerce Backend API

A backend e-commerce system built with Java and Spring Boot.  

---

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Docker

---

## Features

### Product Module (Completed)
- Create product
- Get all products
- Get product by ID
- Delete product
- PostgreSQL persistence
- RESTful API design
- DTO-based request/response handling
